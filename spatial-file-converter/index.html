Spatial File Converter

Convert shapefiles, KML, KMZ, and GPX files between formats. Choose which attribute fields are kept and which field is used for feature names in GPX and KML output.

Files are processed in your browser and are not uploaded to a server.

1. Add a spatial file

For a shapefile, upload a ZIP containing the shapefile components or select the SHP, DBF, SHX, PRJ, and related files together. KML, KMZ, and GPX can be uploaded directly.

2. Choose the fields to keep

All attribute fields are selected by default. Geometry is always retained. Shapefile output uses the DBF 10-character field-name limit.

3. Choose the output

KML and GPX coordinates are WGS 84. When creating a shapefile, the geometry is transformed to the coordinate system selected here and the matching PRJ is included.
